**推荐从 [Microsoft Store](https://apps.microsoft.com/detail/9N4T5SJXMJH3) 安装**：自动更新，支持 x86 / x64 / ARM64，没有“未知发布者”提示。

## 或者直接下载

| 文件 | 说明 |
|---|---|
| `AreYouThere-{VERSION}-win-x64.msi` | **推荐**：安装版（64 位），带开始菜单快捷方式，可在“应用”中卸载 |
| `AreYouThere-{VERSION}-win-x86.msi` | 安装版（32 位系统） |
| `AreYouThere-{VERSION}-win-x64-portable.exe` | 便携版：单个 exe，下载即用，不需要安装 |
| `AreYouThere-{VERSION}-win-x86-portable.exe` | 便携版（32 位系统） |
| `AreYouThere-{VERSION}-win-x64.zip` / `win-x86.zip` | 文件夹版：解压后运行 `AreYouThere.exe` |
| `AreYouThere-{VERSION}.msixbundle` | MSIX 包，含 x86 / x64 / **ARM64**（Microsoft Store 版本使用） |

<!-- unsigned -->
> ⚠️ exe / msi 未签名，Windows 可能提示“未知发布者”，点“更多信息 → 仍要运行”即可。msixbundle 是提交 Microsoft Store 用的包，不能直接双击安装；ARM 设备请从 [Microsoft Store](https://apps.microsoft.com/detail/9N4T5SJXMJH3) 安装。
